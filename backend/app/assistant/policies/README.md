# คลังเอกสารนโยบายของผู้ช่วย (REQ-DAT-010 บรรทัดที่ 2, Q-63 ปิดใน EV-047)

ผู้ช่วยตอบคำถามนโยบายจากไฟล์ในโฟลเดอร์นี้เท่านั้น ไม่ใช้เอกสารในโฟลเดอร์ร่วมของบริษัท
ทุกไฟล์ทำจาก rules.md ที่อยู่ใน Baseline มีหัวไฟล์บอก status, source, baseline และ source_hash
- status: current เท่านั้นที่ค้นได้ ไฟล์ superseded เก็บไว้ให้เห็นว่ารุ่นเก่าถูกกันออก (เรื่องเล่าในหน้าบทเรียนหัวข้อ 4.1)
- source_hash คือ sha256 ของส่วน BR นั้นใน rules.md ถ้า BR เปลี่ยนผ่าน CR แต่ไฟล์นี้ไม่เปลี่ยน test_AC_14_06_policy_matches_baseline จะไม่ผ่าน
- เจ้าของ: RE lead แก้พร้อม CR ที่แก้ BR ในรอบเดียวกัน ผู้อนุมัติเนื้อหาคือ SH-01
