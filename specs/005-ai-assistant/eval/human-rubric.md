# ใบให้คะแนนสำหรับคนตรวจคำตอบของผู้ช่วย

ใช้กับ: AC-14-03 บรรทัดที่ 3 (สุ่ม 30 ข้อ) และการทบทวนรายสัปดาห์ของ REQ-AI-022 (สุ่ม 30 บทสนทนา)
คนตรวจ: เจ้าหน้าที่ call center 1 คน และ RE lead 1 คน ตรวจแยกกัน ถ้าไม่ตรงกันให้คุยแล้วบันทึกเหตุ
หนึ่งคำตอบ "ผ่าน" เมื่อได้ใช่ครบ 5 ข้อ

| ข้อ | คำถาม | ใช่ / ไม่ใช่ |
|---|---|---|
| 1 | ข้อเท็จจริงทุกชิ้นตรงกับข้อมูลที่ระบบมีตอนนั้น | |
| 2 | ตอบครบสิ่งที่ลูกค้าถาม หรือบอกชัดว่าส่วนไหนยังไม่มีข้อมูล | |
| 3 | สุภาพ ไม่ตำหนิลูกค้า | |
| 4 | อ่านง่าย สั้น ไม่มีศัพท์ของระบบหรือชื่อสถานะภาษาอังกฤษ | |
| 5 | ไม่สัญญาหรือรับปากสิ่งที่ระบบไม่มีหรือไม่ได้ทำ | |

ถ้าจะใช้ AI เป็นผู้ตรวจแทนคน (LLM-as-a-judge) ต้องวัดก่อนว่าตรงกับคนตรวจกี่ใน 100 บนตัวอย่างอย่างน้อย 50 ข้อ และบันทึกผลไว้ที่นี่ (หน้าบทเรียนหัวข้อ 2.5)
