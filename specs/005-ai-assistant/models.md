## MD-SEQ-14-01 ตอบคำถาม RAG 5 ขั้น (UC-14 ขั้น 2 ถึง 7, A1 ถึง A3)

```mermaid
sequenceDiagram
  participant C as ลูกค้า
  participant G as รั้วขาเข้า (โค้ด)
  participant I as จำแนกความตั้งใจ (โค้ด)
  participant R as ค้นข้อมูล (โค้ด)
  participant L as LLM (AI)
  participant O as รั้วขาออก (โค้ด)
  C->>G: ข้อความ + customer_id
  G->>G: ผู้ช่วยเปิดไหม เกินเพดานไหม (REQ-AI-009) หลอกให้ลืมกฎไหม (REQ-AI-008)
  G->>I: ข้อความที่ผ่าน
  alt นอกขอบเขต / ห้าม / ไม่แน่ใจ
    I-->>C: ปฏิเสธหรือส่งต่อด้วยข้อความจากโค้ด ไม่ถึง LLM (REQ-AI-005, REQ-AI-007, REQ-AI-012)
  else 5 เรื่องที่รับ
    I->>R: ความตั้งใจ + เลขงาน (ถ้ามี)
    R->>R: เฉพาะงานของผู้ถาม ไม่มีเบอร์ ที่อยู่ พิกัด อายุไม่เกิน 60 วินาที (REQ-DAT-010)
    alt งานไม่ใช่ของผู้ถาม
      R-->>C: ไม่พบงานนี้ในบัญชีของคุณ (บันทึกความพยายาม REQ-SEC-010)
    else
      R->>L: ข้อความสั่งรุ่นปัจจุบัน + ข้อมูลที่ค้นมา + คำถาม
      L-->>O: คำตอบที่แต่ง
      O->>O: เบอร์ เวลา ยอดเงิน เลขงาน ข้อความสั่ง (REQ-AI-008)
      O-->>C: คำตอบ + ที่มาและเวลาอัปเดต (REQ-AI-020) หรือคำตอบสำรองจากโค้ด
    end
  end
  Note over G,O: ทุกคำตอบบันทึกเพื่อสร้างซ้ำ (REQ-AI-013)
```

## MD-SEQ-14-02 เลื่อนนัด (UC-14 A4, E1 ถึง E4)

```mermaid
sequenceDiagram
  participant C as ลูกค้า
  participant A as ผู้ช่วย (agent)
  participant T as เครื่องมือ 3 รายการ (REQ-AI-010)
  participant B as API เลื่อนนัดของลูกค้า (REQ-FN-056, BR-06)
  C->>A: "ขอเลื่อนงาน 1024 เป็น ..."
  A->>T: อ่านสถานะงาน (ระดับ 1)
  A->>T: อ่านช่วงว่างของช่างคนเดิม (ระดับ 1)
  alt วันเวลาไม่ชัด
    A-->>C: เสนอช่วงที่ว่าง ไม่มีอะไรเปลี่ยน
  else เกินกรอบ BR-06 (E1)
    A-->>C: ปฏิเสธ บอกเหตุตามกฎ ส่งต่อคน
  else ชัดและอยู่ในกรอบ
    A-->>C: สรุป (งาน วันเวลาเดิม วันเวลาใหม่ ช่าง) สร้างจากค่าที่จะส่ง API (D-14-03)
    alt ลูกค้ากด "ไม่ใช่" (ครั้งที่ 2 = E4 หยุดและส่งต่อ)
      C->>A: ไม่ใช่
    else ลูกค้ากด "ยืนยันเลื่อนนัด" (ระดับ 2)
      C->>A: ยืนยัน
      A->>T: เลื่อนนัด ด้วยค่าเดิมของสรุป
      T->>B: ทำด้วยสิทธิ์ของลูกค้า (REQ-SEC-010) ตรวจ BR-06 อีกครั้ง
      alt หมดเวลาหรือผิดพลาด (E3)
        B--xT: ไม่ได้คำตอบ
        A-->>C: ยังไม่ทราบผล ส่งต่อเจ้าหน้าที่ ไม่เรียกซ้ำ
      else สำเร็จ
        B-->>T: เวลานัดใหม่
        A-->>C: เลื่อนแล้ว และบันทึกการกระทำ (REQ-AI-013)
      end
    end
  end
```
