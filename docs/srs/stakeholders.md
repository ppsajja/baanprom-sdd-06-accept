## 2. ภายในและภายนอกองค์กร

ภายในองค์กร (บ้านพร้อม)
- เจ้าของธุรกิจ
- ทีมตรวจสอบและอนุมัติผู้ให้บริการ
- ทีมปฏิบัติการงานด่วน
- ฝ่ายดูแลลูกค้า (call center)
- ฝ่ายการเงิน
- ทีมพัฒนา
- ทีมทดสอบ

ภายนอกองค์กร
- ผู้ใช้บริการ (ลูกค้า)
- ผู้ให้บริการอิสระ (ช่าง)
- ผู้ให้บริการนิติบุคคล
- นิติบุคคลหมู่บ้านและคอนโด
- ผู้ให้บริการชำระเงิน
- หน่วยงานกำกับดูแล

## 3. เช็กลิสต์บทบาทสากล 13 บทบาท

| บทบาท | ในเคสบ้านพร้อมคือใคร |
|---|---|
| ผู้ใช้หลัก (Normal operator) | ลูกค้า และช่างอิสระ |
| ผู้ใช้ทางอ้อม (Indirect user) | ผู้สูงอายุที่ลูกจองให้, แม่บ้านที่เป็นคนเปิดประตูรับ |
| ผู้ดูแลการใช้งาน (Operational support) | ฝ่ายดูแลลูกค้า, ทีมปฏิบัติการงานด่วน |
| ผู้ดูแลระบบและข้อมูล (Maintenance, data steward) | ทีมไอที, ทีมตรวจสอบและอนุมัติผู้ให้บริการ |
| ผู้อนุมัติและผู้จ่ายเงิน (Purchaser, sponsor) | เจ้าของธุรกิจ, ฝ่ายการเงิน |
| ผู้ได้ประโยชน์เชิงธุรกิจ (Functional beneficiary) | ฝ่ายการตลาด, ผู้บริหารที่ดูตัวเลขการเติบโต |
| ผู้กำกับดูแล (Regulator) | เจ้าหน้าที่คุ้มครองข้อมูล, หน่วยงานกำกับ, สรรพากร |
| ผู้ตรวจสอบ (Auditor) | ผู้ตรวจสอบภายใน, บริษัทประกันภัยเมื่อเกิดความเสียหาย |
| ผู้ควบคุมทางเข้า (Gatekeeper) | นิติบุคคลหมู่บ้านและอาคารชุด |
| ผู้เสียประโยชน์ (Negative stakeholder) | ผู้รับเหมาคนกลางที่เดิมเป็นคนหาช่างให้ลูกค้า |
| ผู้ใช้ที่มีข้อจำกัด (Constrained user) | ผู้สูงอายุที่อยู่บ้านคนเดียว, ผู้ไม่ถนัดสมาร์ตโฟน, ผู้พิการทางสายตา |
| ระบบอื่นที่ต้องคุยด้วย (System stakeholder) | Thai-ID, DBD-ID, ผู้ให้บริการชำระเงิน, บริการแผนที่ |
| ตัวแทนอัตโนมัติ (AI agent) | ตัวจับคู่งานด่วนอัตโนมัติ |

## 4. Power-Interest Grid (ขนาดวงกลมแทนผลกระทบ)

| ช่อง | กลยุทธ์ | ใครอยู่ช่องนี้ |
|---|---|---|
| อำนาจสูง ความสนใจสูง | จัดการอย่างใกล้ชิด | SH-01, หัวหน้าฝ่ายปฏิบัติการ, SH-05 (ย้ายมาช่องนี้เพราะเรื่องข้อมูลส่วนบุคคลแก้ทีหลังไม่ได้) |
| อำนาจสูง ความสนใจต่ำ | ทำให้พึงพอใจ | ฝ่ายการเงิน |
| อำนาจต่ำ ความสนใจสูง | ให้ข้อมูลต่อเนื่อง | SH-02, ฝ่ายดูแลลูกค้า |
| อำนาจต่ำ ความสนใจต่ำ | ติดตามเป็นระยะ | ร้านขายอะไหล่ในพื้นที่ |

ผลกระทบสูงแต่อำนาจต่ำ (ต้องระวังเป็นพิเศษ): SH-03 และ SH-04
